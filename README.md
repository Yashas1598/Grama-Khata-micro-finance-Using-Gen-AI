# Grama-Khata (Micro-Finance) – Android App

Grama-Khata is a simplified digital ledger Android application developed for village shopkeepers and small retailers to manage customer credit records digitally. The application replaces traditional handwritten “Vahi” bookkeeping with an easy-to-use mobile solution that helps track customer dues, record payments, and send WhatsApp/SMS reminders.

The app focuses on simplicity, accessibility, and trust-based financial management for rural and small-scale businesses.

## Features

* Customer profile management
* Credit and payment transaction tracking
* Real-time due/balance calculation
* Due dashboard for pending payments
* WhatsApp/SMS reminder integration
* Offline-first local database support
* Simple and user-friendly UI

## Technologies Used

* Kotlin
* Android Studio
* Jetpack Compose / XML
* Room Database
* MVVM Architecture
* Android Intents
* GitHub
* Generative AI tools (ChatGPT, Gemini)

## Objectives

* Digitize traditional credit bookkeeping
* Reduce manual calculation errors
* Improve financial tracking for small retailers
* Provide easy reminder functionality
* Build a lightweight and accessible Android solution
